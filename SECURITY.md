# Security policy / 安全政策

## Reporting a vulnerability

Please **do not** open a public issue for a vulnerability in the contracts or in code that signs or
sends transactions. Use GitHub's private vulnerability reporting instead (the repository's
**Security** tab → **Report a vulnerability**). Include what is affected, how to reproduce it (an
anvil-fork or Foundry test is ideal) and the impact you expect. You will get an answer as soon as
possible; please give a reasonable time to fix before any disclosure.

Out of scope: losses from running the software with your own configuration (unprofitable trades,
gas spent on reverted transactions, bad market choices). The software comes without warranty.

## 回報漏洞

合約，或是會簽名、送交易的程式碼有漏洞時，**請不要**開公開的 issue。請改用 GitHub 的私密漏洞回報
（repository 的 **Security** 分頁 → **Report a vulnerability**）。請附上受影響的部分、重現方式（最好
是 anvil fork 或 Foundry 測試）和你預期的影響。我們會盡快回覆；公開揭露前請保留合理的修正時間。

不在範圍內：用你自己的設定執行本軟體造成的損失（不賺錢的交易、revert 交易花掉的 gas、選錯市場）。
本軟體不提供任何擔保。
